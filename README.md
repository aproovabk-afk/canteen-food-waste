# Canteen Food Waste Reducer

A web app that helps college canteens cook the right amount of food.

## Features
- Enter meals cooked and sold each day
- See waste and waste percentage
- Get a suggested quantity for tomorrow
- Donate leftovers alert for NGOs

## Tech stack
Python, Flask, SQLite, HTML/CSS

## How to run
pip install -r requirements.txt
python app.py
Open http://127.0.0.1:5000
